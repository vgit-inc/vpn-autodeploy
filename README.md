# vpn-autodeploy
Script for autodeploy vpn on new server



3x-ui-with-intermidate-proxy-server-start.ru
```bash
bash <(curl -Ls https://raw.githubusercontent.com/vgit-inc/vpn-autodeploy/main/scripts/3x-ui-with-intermidate-proxy-server-start.ru.sh)
```
```bash
curl -Ls -o /tmp/3xui-deploy.sh https://raw.githubusercontent.com/vgit-inc/vpn-autodeploy/main/scripts/3x-ui-with-intermidate-proxy-server-start.ru.sh
sudo bash /tmp/3xui-deploy.sh
```
